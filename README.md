# Leash

Leash is a Mac menu bar app for metered networks. On a network you mark as a data plan, it counts what each app downloads and uploads, blocks the apps you choose and holds the Mac to a daily allowance.

## Roadmap

Leash is in early development and doesn't run yet:

- [ ] Core logic: plan allowance, app identity, rules and usage totals
- [ ] Content filter extension that counts and blocks traffic per app
- [ ] Menu bar app and settings window
- [ ] 1.0: First release on the Mac App Store
